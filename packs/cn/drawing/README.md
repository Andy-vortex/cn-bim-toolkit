# 中国家装施工图约定包

让 Bonsai（IfcOpenShell 的 Blender 插件）出的图看起来像国内家装施工图。只放数据和薄胶水，不改 Bonsai 本身。

## 包里有什么

| 文件 | 作用 |
|---|---|
| `cn.css` | 样式表，只含本包的覆盖规则（出图时自动接在本机 Bonsai 的 default.css 后面，见 `drawset.configure_project`）：长仿宋字体和标注字号（字号即字高，和 CAD 的文字高度一致；GB/T 50001-2017 要求汉字 ≥3.5mm、数字和字母 ≥2.5mm：含汉字的字最小用 small 档 3.5mm，只有数字、字母的小字用 num 档 3.0mm，楼面标高的数字和"（层高 …）"同 small），线宽组 b=0.5mm，承重墙涂黑，新砌隔墙斜线填充，水电和洁具符号统一线宽 |
| `symbols.json` | 平面符号库：五孔插座、防溅插座、专用三孔插座、空调插座（K）、电视插座（TV）、网络插座（TD）、单联、双联、三联开关，单联、双联、三联双控开关（多联双控只在门口合成多联面板时用到，`on_demand`：用到才建 IFC 类型）、强电箱、弱电箱、局部等电位端子箱（LEB）、冷水点（L）、热水点（R）、排水点（P）、吸顶灯、筒灯、灯带、坐便器、台盆、地漏、护理床、紧急呼叫、无障碍扶手、视频监控。字母用折线画，跟着符号转。给排水点带 `system`（建模时归到冷水、热水、排水系统），双控、三联开关的类型带 `Pset_SwitchingDeviceTypeToggleSwitch`。每个符号带图例名称和默认安装高度（`default_height`，只在这里定义：图例写它，图上只标和它不同的点位）。插座、开关、吸顶灯、筒灯、地漏、强弱电箱、给排水点、紧急呼叫、监控带 `paper_scale: 50`：在任何比例下都按 1:50 时的纸面大小画（插座约 4.4mm、开关约 5.8mm、地漏约 2.8mm、紧急呼叫约 4.8mm），图例也一样大；洁具、家具、扶手是实物，按实际尺寸画；冷水、热水点的圆圈画在插入点两侧，免得一对叠在一起 |
| `cn-mep.css` | 水电图（`make_plan_set --mep`）追加的样式：家具、洁具淡显，开关到灯的接线细实线；只接在这几种视图的样式表后面 |
| `cn-ceiling.css` | 顶面布置图（`make_plan_set --kinds ...,ceiling`）追加的样式：吊顶块（`IfcCovering`）的轮廓和叠级线加深到 0.25，灯带虚线，铝扣板板缝网格细线，吊顶标注引线端头的实心圆点；只接在顶面布置图的样式表后面 |
| `cn-floor.css` | 地面铺装图（`make_plan_set --kinds ...,floor`）追加的样式：砖缝细线、门槛石浅灰填充、压条、起铺点记号、找坡箭头；只接在地面铺装图的样式表后面 |
| `cn-lights.css` | 灯具定位图接在 `cn-ceiling.css` 后面：吊顶造型线淡显 |
| `conventions.json` | 国内出图约定（数据）：门窗类别和编号代号（FDM 入户门、M、SM、TLM、ZDM 折叠门、JLM 卷帘门、XZM 旋转门、MLC、FM、C、TC，顺序就是门窗表的顺序）、IFC 开启方式到类别的对应、门窗默认高度和窗台高、高窗的窗台高、入户门和电梯层门的判断词表、防火等级与耐火时间的换算；三道尺寸的间距、轴号圈大小；表格字号；图框和视图标题的尺寸、字号（`titleblock`，生成模板和出图读同一份）；墙体图例的名称（按墙材质，颜色在 `cn.css`）。代码（`src/jiazhuang/conventions.py`）只读取，缺文件或缺项时直接报错。标注字号不在这里，在 `cn.css` |
| `titleblocks/A3-CN.svg` | 中文 A3 横式图框。左侧装订边；右侧竖向标题栏自上而下：设计单位和签章区（留白）、工程名称、设计/校对/审核（每行实名、签名两格）、比例、日期、附注一句"方案图，须专业复核及现场复尺后施工"、指北针（直径 24mm）、图名、图号（右下角）。字号只有两档 |
| `titleblocks/A3-CN-TABLE.svg` | 表格类图纸（图纸目录、门窗表）用的 A3 图框：和 A3-CN 完全相同，只是不画指北针。`drawset.make_table_sheet` 自动选用 |
| `markers-CN.svg` | 出图标记：楼面标高符号（GB/T 50001 的等腰直角三角形，高 3mm，细实线，挂在标高线右端下面）；引出线端头（实心圆点，直径 0.8mm，代替 Bonsai 的箭头）。出图时 `drawset.configure_project` 把本机 Bonsai 自带的 markers.svg 拷进输出目录的 `work/drawings/assets/markers.svg`，同 id 的标记换成这里的；`annotate.level_mark` 按这里的宽高给符号留地方。纯 ASCII |
| `view-title-CN.svg` | 视图标题：图名（大号字）、比例（小号字）同一基线，图名下粗实线（出图时改成图名的长度），没有 Bonsai 自带的编号圈；放在视图下方居中。出图时拷成输出目录的 `work/layouts/assets/view-title.svg`，Bonsai 排图纸时用它 |

三个模板都由 `python tools/make_titleblock.py` 按 `conventions.json` 的 `titleblock` 生成（纯 ASCII，名字不和 Bonsai 自带的模板重名）。

换一套约定：把整个目录复制一份改（可以放在别的盘或网络共享上），环境变量 `JZ_DRAWING_PACK` 指向它。样式表、图框、视图标题、出图标记、符号库和 `conventions.json` 都只从这一个目录读（整包替换，不和本包合并）；改了 `titleblock` 后在设好环境变量时重新跑 `tools/make_titleblock.py`。包要完整（上表的文件，`A3-CN-TABLE.svg` 可以没有）：缺了哪个，出图脚本解析完参数就报一行错（列出缺的文件），退出码 2，不建输出目录。

## 怎么接到 Bonsai 上

- **样式表、图框目录和中间文件目录**：写进 IfcProject 的 `BBIM_Documentation` 属性集（`StylesheetPath`、`TitleblocksDir`，以及指到输出目录 `work/` 的 `DrawingsDir`、`SheetsDir`、`LayoutsDir` 等），见 `src/jiazhuang/drawset.py: configure_project`。路径都相对 IFC 所在目录写；约定包和输出不在同一个盘时，`TitleblocksDir` 写绝对路径。
- **符号**：做成 IFC 类型（IfcOutletType 等）。类型带两种表达：
  - `Model/Body`：盒子，给三维渲染用。
  - `Plan/Body/PLAN_VIEW` 或 `REFLECTED_PLAN_VIEW`：二维符号。

  构件用 `type.assign_type` 关联类型。Bonsai 出平面或顶面图时优先用 Plan/Body，所以图上画的是符号，不是盒子投影。见 `src/jiazhuang/symbols.py`。

  有 `paper_scale` 的符号在比例不是 1:paper_scale 的视图上改用 Bonsai 的 SYMBOL 标注画（`drawset.add_view`）：每个点位一个，位置和点位相同，`EPset_Annotation.Symbol` 写符号键，关联到点位；Bonsai 画成 `<use href="#cn_…">`，单位是纸面毫米。符号代表贴墙的点位，要整个画在点位所在的房间里、不压墙：在点位的转角上再试 0°、90°、270°、180° 和几种变体（`_m` 左右镜像，开关的斜线朝另一侧；`_r`、`_l` 整个画到插入点一侧，贴着墙角的紧急呼叫），取第一个笔画不压墙、不出房间、不压门扇的；转 90°、270°、180° 只在不转向的各种变体都压墙或出房间时才用（转过去符号就离开了点位所在的墙），不转向就有不压墙、不出房间的写法时，在这些里取压门扇少的（`annotate.paper_pose`；Bonsai 的 SYMBOL 只认转角、不认镜像，所以镜像和挪到一侧做成另一个定义，符号键带后缀，所以 `symbols.json` 里的符号键不能以 `_m`、`_r`、`_l` 结尾，读符号库时会报错）。符号定义（连同变体）由 `symbols.svg_defs` 生成，出图时和本机 Bonsai 自带的 symbols.svg 合成一份写到 `work/drawings/assets/symbols.svg`（`SymbolsPath`）；`drawset.render_view` 出图前会检查，缺了就补写。分区、分段图切口处的 `<use>` 和模型线一样被裁切框裁掉。这些类型同时按类型加进视图的 Exclude（`IfcOutlet, query:"type.Tag"="cn_socket"`），模型线里不再按实际尺寸画一遍；同一类里没有 `paper_scale` 的类型（吸顶灯）照常画。1:50 的视图不换，和以前一样。1:200 及更小的总图不画点位（插座、开关、地漏、紧急呼叫、监控）和扶手，图例也不列。
- **墙的画法靠材质名区分**：`cn-bearing`（疑似承重墙、外墙）涂黑，`cn-existing`（原有隔墙）灰色，`cn-partition`（新砌隔墙）填斜线，`cn-demolish`（拆除）红色虚线。注意 Bonsai 生成样式类名时会**去掉连字符**，CSS 里要写 `material-cnbearing`。
- **纸面**：图上只有图形、尺寸、轴号、编号、图例、视图标题和标题栏；统计、自查结论、拆改计数只在报告、xlsx 和 IFC 里。图例（`drawset.add_legend`）不加外框，每行"符号 | 名称 | 默认高度"；点位、洁具家具按本图实际画出的种类各一行（模型线和 SYMBOL 都算，平面图上不画的吸顶监控不列），墙体按本图实际画出的墙材质各一行，色块用和墙相同的 CSS 类（"疑似承重墙/外墙（待结构复核）"就挂在这一行）；分区图的图例在右侧预留的一栏，总图的在视图标题下面；写过简称的图（小比例总图，1:150 上写不下全名的小房间）末尾加一行简称对照，按这张图上实际写过的简称生成（总图上 "--labels" 的 legend_text 接在后面作补充说明）；没留图例栏的平面图（分段图、示例户型的平面布置图）只画墙体图例，放在图面上离图例栏位置最近的空地（`drawset.place_legend`），不挪视图、不改比例，放不下就不画（日志 `legend skipped`）。一套图的图例同宽，同一条名称在各张图上断法一致。图例名称、标题栏里的长名字折行（`drawset.wrap_text`）：不多出一行时断在空格、标点、"/"后面或"（"前面（括号外的优先），否则在字间断、最后两行匀开；行首不放收尾标点和"/"，行尾不放"（"。分区、分段靠总图上的分区线和各段图号、分段图切口处的"接 x-xx"索引。表格页一页只有一张表时不写表名，表下脚注只写表里看不出来的（电梯层门由厂家配套、樘数为单层数量）。

## 自动标注（`src/jiazhuang/annotate.py`）

- **国标三道尺寸**：由里到外依次是洞口/墙垛（两端与总尺寸一致，中间点为本侧的轴和洞口边）、轴线（本侧画了轴号的轴）、总尺寸（外墙外皮外包，分段图内部切口一侧量到切口轴）。第一道离图样最外轮廓 10mm，各道间距 7mm（GB/T 50001-2017 第 11.3 节）；某一侧有平开门扇扫到外轮廓以外（外开的入户门）时，从门扇外边算起。四个方向各算一次，和外一道重复的自动省略；首末端点没有轴号的画尺寸界线。识别出来的模型（墙在洞口处断开、没有洞口对象）按门窗构件沿外墙投影算第一道。写不下数字的小段（约小于 300）数字错开到第二排或旁边，同一排相邻数字至少隔 0.5mm（尽量 1mm），不压起止符和轴号引线，同值的数字不上下叠放；几段挤在一起时从左到右、从右到左、短的先放几种先后都试，取挤的、离本段中点超过 5mm 的最少的一种；排完后离本段中点超过 5mm 的数字再挪回本段附近，只挪这些数字，已经在本段附近的数字不会被挤走：先试本段附近的三排（尺寸线另一侧那排是 GB/T 50001 的上下错开注写，不压相邻一道的数字，最外一道不压轴号圈的引线；另一侧离相邻一道不到"数字带 + 一个字高"时——7mm 的间距都是这样——在那一道的范围里不用另一侧那排，免得横着读成那一道的数字），再按数字的实际墨迹宽在本段正上方居中写（段比数字略宽、离轴号引线仍有 0.3mm 时），还不行用引出线（GB/T 50001）：数字写在相邻段（相邻段比数字还窄时再隔一段）以内的空位上，Bonsai 的 TEXT_LEADER 从数字一端顺着数字引出一小段，再按 45°、60° 或 90° 折到本段中点的尺寸线上，线端是圆点；引线不穿过别的数字和引线、全长不超过 12mm，折点离同一排别的数字 0.6mm 以上（读不成"600—900"），竖直的一段不贴着轴号引线走；引不出去时把挡路的一个数字挪开（它也可以引出）；都不行才写在离本段最近的空位上（日志 `dim text far`）。尺寸数字一律用同一个字号，不缩字；引出的记日志 `dim text leader`。角上的数字不伸进相邻一侧的尺寸区；尺寸界线遇到数字断开。
- **轴号**：原图是局部轴线时，某一侧只画伸到这一侧的轴。
- **楼面标高**：Bonsai 的 PLAN_LEVEL 标注，只写说明文字（米，三位小数，±0.000），标高符号是本包 `markers-CN.svg` 的等腰直角三角形；放在门窗编号之后找空地（先交通空间）。一个标准层代表多层时，一套图只用一种写法：层数不多（≤4）时每张图都放得下就按 GB/T 50001 单列叠注（本层在下，其余各层加括号），否则整套写"最低～最高（层高 h）"，房间窄时整套把"（层高 h）"写到标高线下面。数字、叠注的各层和"（层高 h）"同一字号（small 3.5mm）。标高先避开房间名标注点所在的竖条，放不下就至少离开标注点 11mm；房间名后放，和标高上下至少空一行，免得标高读成房间名的一行。
- **分段平面**：整层一张 A3 放不下 1:100 时自动沿 x 切段，切口优先选变形缝和分户墙所在的轴，图名用切口轴号（"四～十七层 1～14轴平面图"），总图改为组合平面图。切口处画 Bonsai 的折断线（BREAKLINE），折断符号放在不压字的地方，注接图图号；组合平面图上的分区线用 `cn.css` 的 `jz-zoneline`（点划线），遇到房名断开。模型只画到裁切框（切口）：裁切框存在视图的 `JZ_View` 属性集（CropXMin/CropYMin/CropXMax/CropYMax，相对相机中心，项目长度单位），`drawset.render_view` 读它给模型线加 clipPath，从保存的 IFC 重开重出也一样。

- **灯具定位图**（紧跟顶面布置图，同一个顶面视图）：墙、窗、吊顶造型线（淡显，`cn-lights.css`）、全部灯具符号、房名、图例，不标标高和材料。定位尺寸量灯的真实位置（`annotate.light_dims`）：吸顶灯横竖各一道到墙（近的那面优先，穿过筒灯符号时尺寸线在符号处断开，只有被别的灯符号挡住或数字无处可放才量远的那面）；筒灯符号一律以灯为中心画；同一条横线或竖线上成排的筒灯（相邻两盏不超过 `../mep/points.json` 的 `spacing_max × row_break`，再远断成两排各标各的）一道尺寸：尺寸线和灯排平行、朝房间里面偏开 `conventions.json` 的 `dimensions.light_dim_mm`（窄处收窄），起止符同外围尺寸链，每盏灯一条短尺寸界线（遇到字断开），连续相等的间距合成一段写"4×1210=4840"（主灯的尺寸线正好横穿、沿线挪不开时逐段写），只标一端到墙（`dimensions.light_dim_ends` "one"：一端到墙加各段间距已经定死这一排；一圈里的各排按顺时针只标起点那端，每个拐角只落一个小数字；不成圈的排两端各试一次，标数字放得下、引出少的那端；隔着大空档的那头不量；没标的那端尺寸链到最后一盏灯为止。"both" 是首尾各标一段）；同一道尺寸上相邻两个数沿线至少隔一个数字宽，放不下的换另一侧或引出；同一间房里相对的两排灯位对齐、纸面相距不超过 `dimensions.light_dim_share_mm`（20mm）、中间没有别的灯时共用一道尺寸，每对灯一条尺寸界线穿过两盏；数字写在朝房间里面的一侧居中，写不下错开一排、换另一侧，再不行用水平、竖直两段的短引线引出；各排的合并写法先排，首尾到墙的小段后排。在吊顶边带正中的灯排不逐排标离墙尺寸，图例末尾一行"未注明的筒灯居吊顶边带正中"（边带宽度在顶面布置图上）；不在正中的（窄过道里一排在中线上、平顶沿中线的）标一道到近的那面墙。单独一盏在边带正中的沿边带量到近的那面墙，别的横竖各一道。灯带不标。
- **顶面图**（示例户型 `make_demo_set` 的 JZ-03）：吊顶名称和吊顶标高作为一组（标高在上、名称在下），和房间名同一套避让，不压灯具，离开 0.6mm，灯具不夹在两者中间；标高和楼面标高同一种画法（PLAN_LEVEL，米、三位小数，正数不写"+"）；没吊顶的房间写"原顶刷白"。

参考了下面四本标准的常用画法：

- GB/T 50001-2017《房屋建筑制图统一标准》
- GB/T 50104-2010《建筑制图标准》
- GB/T 50786-2012《建筑电气制图标准》
- GB/T 50106-2010《建筑给水排水制图标准》

## 已知限制

- 1:150、1:300 这类小比例图上，小卫生间、窄居室放不下房间名、房外附近也找不到不贴着别的房名组的空地引出时，字会贴墙、转 90° 压床或出房间一点（日志 `room label touching`、`room label over furniture`、`room label spills`）；总图上的床位房间名会压床。
- 紧挨着轴线的小段（如 100 的墙垛）数字不能压轴号引线，只能写在旁边段的上方（离本段中点 5mm 以内）或用引出线；夹在两根轴号引线之间、和数字差不多宽的段，数字按墨迹宽居中写在本段正上方，两头离起止符的短线只有零点几毫米，起止符的尖可能碰到数字的边。1:150 上两根轴线之间挤着"墙垛 + 洞口边 + 墙垛"几段小段时（如 400、100、1000、100、400 挤在 13mm 里），有的数字只能写在相邻段上、紧贴本段的尺寸界线（GB/T 50001 的写在尺寸界线外侧），和相邻段自己的数字（在另一排）同在一段上方；引出的数字有时和上下相邻一排的数字叠成两层（引线指明是哪一段）；连引出线也排不开时写在离本段最近的空位上（日志 `dim text far`）。引出线从数字一端在数字的半高处水平引出（Bonsai 的 TEXT_LEADER 把字写在折线第一点、线也从这一点画起，中间没有空隙），引线在数字前面时，这一小段横线贴着数字，细看像负号（如"-750"）。
- SYMBOL 标注不随点位联动：在 Bonsai 里挪了点位，要重新出图（`drawset.add_view` 重建 SYMBOL）；点位放置带镜像时，符号只跟着转、不镜像。
- 点位符号在 1:100、1:150 上比实物大（1:150 时是 3 倍）：靠墙密排的点位符号会互相挨着；门边只有一小段墙时，开关的斜线朝哪边都压墙，只能压门的开启线。1:150 的小卫生间（约 1.5m×2.4m，放了坐便器、紧急呼叫、插座）连简称都写不下时，字会贴着门扇或出房间一点（日志 `room label spills`）；窄天井里两樘窗挨着时，卫生间窗的编号写不进房间、也写不到窗外，只能拉长引线（日志 `tag leader long`）。窗正前方贴着点位符号（如两床之间床头的紧急呼叫）、窗外又是尺寸数字时，编号的引线仍会穿过符号（日志 `tag leader over symbol`；不穿的话编号只能压在床上）。1:150 的小卫生间里写了简称（"卫"）时，窗、门的编号可能和它上下紧贴。
- 吸顶的点位（视频监控，2.6m）在平面图的剖切面以上，平面图上不画，图例也不列。
- 重出视图依赖输出目录的 `work/`：点位符号的定义、合并样式表、出图标记都在 `work/` 下（`drawings/assets/symbols.svg`、`cn-combined.css`、`drawings/assets/markers.svg`）。只拿 `model.ifc` 在 Bonsai 界面里重出时，要连同 `work/` 一起拿，或者先跑一次 `drawset.configure_project`；用 `drawset.render_view` 重出时缺了的点位符号定义会补写，样式表和标记仍要 `work/`。
- 尺寸界线只画在没有轴号引线的首末端点上，中间各点没有（分区图的轴号引线穿过各道尺寸）。
- 灯具定位图的成排尺寸只认横平竖直的灯排（坐标相等、差 5mm 以内算一排）：斜着的一排（包括整套户型转了角度时的各排）认不出来，每盏各标横竖两道到墙的尺寸，位置是对的，只是数字多。
- 只支持横平竖直的墙和矩形房间，用的是包围框算法；斜墙、弧墙上的外窗不进第一道尺寸（记日志）。
- 入户门的"户内与公共交通空间之间"一条要靠空间的户信息（`JZ_Space.Unit`），模型没有户信息时只认名称写明的和外墙上开向玄关、门厅的平开门。
- 分段图的模型裁切框是本工具链的约定（`JZ_View`），Bonsai 不认：在 Bonsai 界面里直接点"生成图纸"重出分段视图，切口外的墙会画进尺寸、轴号区，要用 `drawset.render_view` 重出。
- 1:150 的密集核心筒里，走道放不下所有引出线编号时，走道墙上别的门的编号会换到门的另一侧，离洞口 8～12mm；核心筒里门挨着门时，引出的字只能写在别的门的门前（日志 `tag leader in front of a door`），字离别的门比离自己的门近的也不少，两樘同号的井门编号放不开时会上下相邻（日志 `tag leader stacked`）；引出的字连不隔墙的位置都找不到时，最后一档只避开墙和字、引线可能穿墙（日志 `tag leader crowded`）。走道房名的预留只对窗的编号生效，井门的编号仍可能占走道，"通道"这类走道名就从房外引出。
- 组合平面图（1:300）上，夹在电梯井和别的房间之间的"消梯"只能从井里引到旁边房间，那里的房名（如"厨"）写在正上方时，引出的字找不到中线错开半个字的位置，仍可能读成一列。
- 平面上的高窗仍是 Bonsai 的普通窗画法（没有按 GB/T 50104 画虚线、注 h=），只在门窗表里注明窗台高和"高窗"。
- 图例、表格脚注、标题栏里长名字的折行、视图标题下粗线的长度，是排好图纸后写进图纸 SVG 的：在 Bonsai 界面里重新排这张图纸时，图例和脚注没有，长名字不折行，粗线回到模板的默认长度（视图标题的位置在排版文件里，不变）。
- 平面几何（`openings.PlanGeometry`：门窗、墙、建筑轮廓）按整个 IFC 文件算，不分楼层：一个 IFC 里有几层时，编号避让、外墙和外窗判断、门窗表会把别的楼层算进来。现在的流程都是一个 IFC 一层。
- 水电图上点位密的地方（1:100 的小卫生间、厨房台面），高度标注要用引出线，个别引出也放不下时会贴着别的字（日志 `height crowded`）；接线弧线不绕开门扇。L 形房间里两头隔着拐角时，连直线也会出房间（取出房间最短的一种，日志 `wire outside room`）。
- 按户出图（`make_plan_set --unit`）只画这一户的房间和围着它的墙：入户门外没有走道，别户和核心筒不画；没归户的房间不会出现在任何一户的图里，出图前先在识别结果里把它归户（出图日志 `JZLOG unit … doors lead to rooms not in the unit` 列出这一户的门通向的别的房间）；门窗编号在这一户里重新编，撞号后缀可能和整层图不同。合成标准层的户 A3 上放不下 1:50，是 1:80；1:80 上门边墙垛短的双控开关仍压门扇（比 1:100 少）。
