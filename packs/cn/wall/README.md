# 墙面约定包

`rules.json`：按房间类型给每面墙一种缺省做法（乳胶漆、墙砖、壁纸，加不加踢脚线、贴到多高），意图可以逐间、逐面改；程序按固定的规则算墙面轮廓、排墙砖、定出哪些墙的立面和立面字母。程序在 `src/jiazhuang/wall.py`（只用 shapely），命令行 `scripts/wall.py`。流水线里排在地面之后、建模之前（要读门窗、吊顶底、点位、地面完成面）：识别 → 家具 → 吊顶 → 水电 → 地面 → **墙面** → 建模 → 出图。

```bash
python scripts/wall.py build/furnish/recog.json build/flooring/demo/scheme.json build/flooring/demo-wall --intent packs/cn/wall/example-intent.json
blender -b --python-exit-code 1 --python scripts/make_plan_set.py -- build/furnish/recog.json build/flooring/demo-set --scheme build/flooring/demo-wall/scheme.json --kinds plan,floor,ceiling,mep --title "{kind}"
```

`--unit U1,U2` 只重做这几户，别的户以前生成的墙面原样留着。退出码：0 成功（`JZLOG done <输出目录>`）；1 有违规或意图写错，方案和报告照样写出（`JZLOG failed`）；2 参数或输入错误（文件不存在、意图结构不对、户号不存在），不建输出目录。

各张平面类图都排除墙面面层（不带 `--kinds elev` 时有没有墙面数据图面都一样）；加 `--kinds elev` 时按墙面数据出 1:50 室内立面图（含材料标注、墙砖缝、踢脚线和平面内视符号）。

## 规则表

| 键 | 内容 |
|---|---|
| `sources` | 依据：条文号（或"惯例""推断"）、自拟概括、参数、可信度、状态；条文和网页都待原文核对 |
| `materials` | 材料：图上和表里写的名字 `name`、`kind`（`paint` 涂料、`tile` 墙砖、`wallpaper` 壁纸、`skirting` 踢脚线）、墙砖规格 `size` [短边, 长边]、缝宽 `joint`、损耗率 `waste`、踢脚线高 `height`、建模时面层板的厚度 `thickness`、建模时的材质名 `css` |
| `rooms` | 房间类型（`../furniture/room_types.json`）→ 缺省做法：`finish` 材料键；`top` 贴到哪（`"full"` 到原顶、`"ceiling+100"` 这面墙的吊顶底以上 100，墙砖在吊顶底以上 50～100 之间有一道缝时停在缝上、数字是离楼面的毫米数）；`skirting` 踢脚线材料键或 `false`；`dir` 墙砖 `h` 横贴（长边水平）、`v` 竖贴。认不出的房间用 `other` |
| `elevations` | 出哪些墙的立面：`mode` 缺省方式；`always` 每面都出的房间类型；`fixed` 算柜体、固定家具的家具键（`../furniture/furniture.json` 里的）；`fixed_gap_mm` 家具靠墙边离墙线不超过这么多算贴墙 |
| `layout` | 排砖门槛：边砖不小于 `min_edge_mm`；点位盒子离砖缝不小于 `socket_gap_mm`；门洞边离墙端不到 `door_end_mm` 时这一端算门后 |
| `checks` | 校验门槛（见下面"校验"）和几个几何门槛：墙边外侧 `wall_gap_mm` 以内有墙才算有墙；短于 `open_min_mm` 的没墙段不算开敞；吊顶块离墙 `ceiling_gap_mm` 以内算贴着这面墙，挡住不到 `ceiling_cover` 的墙长时按没有吊顶算；`point_types` 墙上装的点位（按 IFC 类型），离墙线 `point_wall_mm` 以内归到这面墙 |

缺省（都是"惯例"，意图可以改）：

| 房间 | 做法 | 顶 | 踢脚线 |
|---|---|---|---|
| 客厅、餐厅、卧室、书房、过道、玄关（储藏和认不出的也是） | 白色乳胶漆 | 到原顶 | 80 |
| 厨房 | 墙砖 300×600 横贴，缝 2 | 吊顶底以上 100 | 不做 |
| 卫生间 | 墙砖 300×600 竖贴，缝 2 | 吊顶底以上 100 | 不做 |
| 阳台 | 白色乳胶漆 | 到原顶 | 不做 |

没有吊顶的墙，"吊顶底以上 100"按到原顶算；顶高一律不超过原顶（方案 `rooms[].height`，没写用吊顶规则表的 `checks.height`）。

## 墙边、坐标和立面字母

- **墙边**就是 `scripts/furnish.py context` 给的 W1..Wn：房间轮廓去掉门洞条（门口伸进墙厚的窄条）、合并共线的边，逆时针，从最南（再最西）的角起编。
- **墙面坐标** (u, v)：面向这面墙看，u 从左端往右量，v 从本层楼面往上量，毫米。墙边逆时针走，所以墙边的终点 b 在左端、起点 a 在右端（u = 墙长）；`furnish` 的"从起点量"和 u 方向相反。
- **立面字母**：外法线最接近正北（图纸上方）的那面为 A，顺时针 B、C、D，多于四面接着 E、F…（墙边编号倒着走就是顺时针）。房间里每面墙都编字母，开敞边、不出立面的也编，这样出哪几面立面变了字母也不变。一样朝北的两面取长的，再取靠北、靠西的。
- **开敞边**：墙边外侧 `wall_gap_mm` 以内没有墙、也不是门窗洞口（客餐厅之间这类没有墙隔开的边）。整条都没墙的不分做法（`open: true`，只编字母，记一条提醒）；只有一段没墙的，这一段从墙面里挖掉（`open_spans`），也记提醒。

## 每面墙怎么算

1. **做法**：规则表这类房间的缺省 → 意图里整间写的 → 意图里这面墙写的，后写的盖过先写的。
2. **底高** `bottom`：这间房的地面完成面（方案有地面数据时取它所在铺装区的标高，湿区是 -20；没有地面数据是 0）。墙砖压地砖说的是施工顺序（先铺地砖，墙砖立在地砖上），墙面从这里起，不要求第一排整砖。
3. **顶高** `top`：`full` 到原顶；`ceiling+n` 到这面墙的吊顶底以上 n。"这面墙的吊顶底"取贴着这面墙的吊顶块里最低的底；贴原顶的块（窗帘盒）不算；吊顶块只挡住这面墙不到 `ceiling_cover`（九成）长度时按没有吊顶算，贴到原顶才不露墙。墙砖写 `ceiling+n` 的，排砖（第 6 条）以后吊顶底以上 `over_min_mm`（50）到 n 之间有一道横缝时，顶停在这道缝上（W15）：再往上只剩一窄条切块，藏在吊顶里，不贴、不算量；没有缝落在这一段里照旧到 n。300×600、吊顶底 2400、湿区 -20：竖贴停在 2489、横贴停在 2497，最上面一排是整砖。顶写 `full`、写数字的不动。面积、块数、IFC 面层的顶（`Top_mm`）都按停下来的这个顶。
4. **墙面轮廓** `parts`：墙面矩形（u 0～墙长，v 底～顶）减去门窗洞口、减去开敞段；洞口把墙面切成几块时是几块。门窗洞口的竖向范围和建模、吊顶、水电同一套（`openings.rec_size`）：窗台高用识别结果的 `sill`，没有用约定包缺省（凸窗一律缺省）；窗高用识别结果的 `height`，没有用原图编号里的（宽度对得上时），再没有时到统一的窗顶（缺省窗台 + 缺省窗高，2400），窗高 = 窗顶 − 窗台、不小于 `../drawing/conventions.json` 的 `min_window_height_mm`（窗台 1500 的高窗是 900，不会顶到吊顶以上）；凸窗高用识别结果的、编号里的或缺省；门洞落地，门高用原图编号里的或缺省。
5. **踢脚线**：墙面最下面 `height` 高的一条，减去门洞和开敞段。
6. **墙砖排砖**（只有墙砖墙），不搜索、不打分，同样的输入每次得到同样的结果：
   - 竖向和沿墙同一个思路：整砖从露着的一端起，非整砖落在另一端；非整砖小于 `min_edge_mm` 时把网格往起铺那端挪，让它正好等于 `min_edge_mm`（W5、W14）。
     - 贴进吊顶（顶高过这面墙的吊顶底）：露着的是吊顶底。一条缝对齐吊顶底，往下整砖，非整砖落在最下面一排（贴着地面完成面）；最下面一排不够宽就把网格往上挪到它正好够宽，这时吊顶底下露出的最上面一排是一块整砖的下半截，切口藏在吊顶里。300×600、吊顶底 2400、湿区 -20：竖贴最下面一排 100、露出 512；横贴最下面一排 100、露出 204。
     - 没有吊顶、砖不到吊顶（贴到原顶或贴到某个高度）：露着的是顶。从地面完成面整砖起，往上排，最上面一排切；最上面一排不够宽就把网格往下挪到它正好够宽，最下面一排跟着变成非整砖。
     - 墙面不到一块砖高时只有一排，不挪。贴进吊顶、往上挪过的网格，"吊顶底以上 100"上面只剩很窄的一条（上面的例子横贴 2、竖贴 10）：写 `ceiling+n` 的墙顶停在下面那道缝上（第 3 条），这一条不贴；贴到原顶、写了高度的墙照贴，藏在吊顶里的切块不算窄条、数量里照样算。
   - 沿墙：先看两端露不露在外面。阳角（房间轮廓往里凹的角）、旁边是开敞边或开敞段算露着；阴角藏得住；门洞边离这一端不到 `door_end_mm` 算门后，也藏得住。一端露着、另一端藏得住时整砖从露着的一端起，非整砖落在藏得住的一端；这块非整砖小于 `min_edge_mm` 时把网格往起铺那端挪，两端都不小于它。两端一样时对中：试"缝对中"（墙中线上是一条缝）和"砖对中"（墙中线上是一块砖的中线），选边砖宽的那个（一样宽取缝对中），两头的非整砖对称、一定不小于半块。
   - 网格记成 `grid`：`dir` 0、`origin` 一个缝交点、`pitch` 缝距（砖加缝），和地面的 `JZ_Flooring` 同一套。砖缝不存坐标：`flooring.joint_lines(grid, 墙面轮廓)` 现算；数量（整块、切块、含损耗的合计）用 `flooring.quantities`。
7. **出不出立面** `elev`（`why` 写原因）：
   - `finished`（缺省）：`always` 里的房间（厨房、卫生间）每面都出（原因"房间"）；别的房间只出三类墙：有柜体或固定家具背靠着的（`fixed` 里的家具，靠墙边和墙平行、离墙线不超过 `fixed_gap_mm`、沿墙和墙边有重叠，"柜体"）、做法不是涂料的（"做法"）、意图点名的（"意图"）。
   - `all`：每面都出（开敞边除外）。
   - `intent`：只出意图点名的。
   - 意图里某面写 `"elev": false` 的不出（三种方式都是）。

## 意图（可选）

不写坐标，一间房一条，写了的盖过缺省；`walls` 按墙边编号逐面改：

```json
{"elevations": "finished",
 "rooms": [
  {"room": "客厅", "walls": {"W1": {"finish": "wallpaper", "note": "电视背景墙"}, "W3": {"elev": true, "note": "沙发背景墙"}}},
  {"room": "卫生间", "dir": "h", "walls": {"W3": {"top": "full"}}},
  {"room": "主卧", "elev": ["W2", "W4"]}
 ]}
```

| 键 | 写在哪 | 含义 |
|---|---|---|
| `elevations` | 顶层 | 出立面的方式：`finished`、`all`、`intent` |
| `room` | 整间 | 房名或房间 id（同名的几间写 id） |
| `finish` | 整间、一面墙 | 材料键（`materials` 里不是踢脚线的） |
| `dir` | 整间、一面墙 | 墙砖 `h` 横贴、`v` 竖贴 |
| `top` | 整间、一面墙 | `"full"`、`"ceiling+n"`、离楼面的毫米数（不高于原顶，要高于踢脚线顶） |
| `skirting` | 整间、一面墙 | 踢脚线材料键、`true`（第一种踢脚线）、`false` |
| `size`、`joint` | 整间、一面墙 | 墙砖规格 [短边, 长边]（50～3000）、缝宽（0～20） |
| `elev` | 整间：墙边编号列表；一面墙：`true` / `false` | 点名出或不出立面 |
| `note` | 一面墙 | 一句说明（如"电视背景墙"），原样记进方案 |
| `walls` | 整间 | `{"W1": {…}, …}` |

`dir`、`size`、`joint` 只对墙砖起作用。写错的（房间、墙边找不到，材料不认识，键不认识，数不对，`top` 不高于踢脚线顶）只在报告 `errors` 里记一行（`check: intent`），写错的那一项不用、其余照做，退出 1；意图结构不对（不是对象、`rooms` 不是对象列表、`walls` 不是对象）退出 2。公共部分、没有户号的房间不做墙面，意图写了也报一行。

## 输出

方案的 `walls` 每面墙一条（毫米；平面坐标是图纸坐标，`parts`、`openings`、`grid` 是墙面坐标）：

| 键 | 内容 |
|---|---|
| `id`、`room`、`unit`、`wall`、`letter` | `WF-<房间>-<墙边>`、房间 id、户、墙边编号、立面字母 |
| `a`、`b`、`length` | 墙边起点、终点（平面）、墙长 |
| `open` | 开敞边（只有前面这几项和 `elev: false`） |
| `finish`、`material`、`kind`、`size`、`joint`、`dir` | 材料键、名字、类别；墙砖的规格、缝宽、贴法 |
| `bottom`、`top`、`top_rule`、`ceiling`、`height` | 底高、顶高、顶高的写法、这面墙的吊顶底（没有是 null）、原顶 |
| `parts`、`area_m2` | 墙面轮廓（几块，每块 `polygon` + `holes`）、面积 |
| `openings`、`open_spans` | 这面墙上的门窗洞口（`from`、`to`、`bottom`（门洞为 null）、`top`）、开敞段 |
| `grid` | 墙砖排砖网格（`origin`、`pitch`、`start`、`edges` 两端和上下的边砖宽、`quantity` 数量）；不是墙砖为 null |
| `skirting` | 踢脚线（材料、高、`parts`、面积）或 null |
| `points`、`fixed` | 墙上的点位（`u`、`z`、盒子宽高）、背靠这面墙的柜体（plan_id） |
| `elev`、`why`、`note`、`source` | 出不出立面和原因、意图里的说明、做法来自"规则"还是"意图" |

报告 `report.json`：`rooms`、`walls`（有做法的面数）、`open`、`elevations`、`mode`、`layout`（每面墙一行：字母、做法、顶高、出不出立面、排砖起点和边砖）、`notes`、`errors`、`violations`、`counts`，和地面同一套。

## 校验

| check | 记在 | 查什么 |
|---|---|---|
| `no_finish` | violations | 有房间没分到做法（规则表里这类房间和 `other` 都没写） |
| `area` | violations | 墙面面积 = 墙面矩形 − 洞口和开敞段（容差 `area_tol_mm2`）；墙砖的整块 + 切块覆盖的面积 = 墙面面积 |
| `top` | violations | 顶高高于原顶；墙砖、壁纸伸进吊顶不到 `over_min_mm`（已经到原顶的不算）；顶高低于吊顶底（没有吊顶时低于原顶），露出一截没做面层的墙 |
| `points` | violations | 墙上的点位（盒子中心）落在门窗洞口里，或在墙面面层外（高过顶、在开敞段上） |
| `points` | notes | 墙砖墙上的点位盒子离砖缝不到 `socket_gap_mm` |
| `edges` | notes | 切出来窄于 `min_edge_mm` 的条砖（墙端、门窗洞边；整块在吊顶底以上的不算）；吊顶底下露出的最上面一排砖窄于它（砖竖向那条边不到两个 `min_edge_mm` 时才会有）；两端都是阳角或开敞时非整砖露在两端 |
| `walls`、`openings`、`top`、`bottom`、`points`、`fixed` | violations（过时） | 方案里的墙面数据和现在的墙边、背后的墙、门窗、吊顶、地面完成面、点位、柜体对不上：墙面之后改过门窗或重跑过吊顶、地面、水电、家具。`wall.check` 在生成时和 `make_plan_set` 入口都查；出图入口查到时每处一行 `JZLOG stale`（写明重跑 `scripts/wall.py`），退出 1，不建输出目录 |

## 建模

`plan2ifc` 在方案有 `walls` 时每面墙建面层（没有时 IFC 里没有这些构件，别的都不变）：

- 涂料、墙砖、壁纸一个 `IfcCovering`（`PredefinedType=CLADDING`），有踢脚线的另一个（`SKIRTINGBOARD`），Tag 分别是 `WF-…`、`SK-…`。
- 几何是贴墙面的板：竖向轮廓是墙面轮廓，沿室内法线拉伸 `thickness`（面层 8，踢脚线 10、在面层外面）。放置的局部坐标就是墙面坐标：x 面向墙从左往右，y 竖直向上，z 指向室内，原点在墙面左端、本层楼面。
- 材质名是 `css`（`cn-wall-paint`、`cn-wall-tile`、`cn-wall-paper`、`cn-skirting`）。坑：Bonsai 写 SVG 类名时去掉连字符（`cn-wall-tile` → `cnwalltile`），样式表要按去掉以后的写。
- 属性集 `JZ_WallFinish`：`Room`、`Wall`、`Letter`、`Elev`、`Material`、`Kind`、`Bottom_mm`、`Top_mm`、`Area_m2`、`Source`；墙砖另有 `Size`、`Joint_mm`、`Dir`、`Origin`、`Pitch`（墙面坐标）。砖缝不建模。
- 每间房的面层用 `IfcRelCoversSpaces` 挂到房间；构件本身和吊顶、地面面层一样放在楼层里。
- 面层贴着墙、在房间里，剖切高度上会被剖成墙边一条细黑边：`make_plan_set` 在方案有墙面数据时给每张平面类视图的 Exclude 加上这两类（`IfcCovering, PredefinedType=CLADDING + IfcCovering, PredefinedType=SKIRTINGBOARD`），各张图和没有墙面数据时一样。
